# prime:i am not  (Minecraft 1.20.1 - Forge 47.3.0)

كل قوانين ماين كرافت معكوسة.

| الميزة | الوصف |
|---|---|
| السندان/الرمل/الحصى | يطيرون للأعلى بدل ما ينزلون |
| الأغراض المرمية | تطفو وتتعلق فوق الأرض |
| الزومبي والهيكل والزاحف... | يهربون منك |
| البقر/الخراف/الخنازير/الدجاج | يهاجمونك |
| القرويين | كرماء، يعطونك هدايا مجانية (زمرد، خبز...) |
| الايرون قولم | يهاجمك، وإذا مات يطلع 3 بلوكات حديد |
| ضرر السقوط | يعالجك بدل ما يضرك |
| شعار ماين كرافت | مقلوب في الشاشة الرئيسية |

كل ميزة تقدر تطفيها من ملف `config/prime-common.toml`.
